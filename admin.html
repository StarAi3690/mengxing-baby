🛍️ 商品配置（萌星好物 / 积分兑换）

上架 / 下架、调价、改库存均在此配置，点「发布」后全端生效。数据存于云端 CFG::linkage_config.goods。某分类留空数组 [] = 该分类不展示。孩子端每 3 分钟自动刷新。

⭐ 积分兑换商品（SHOP_GOODS）

字段：id / name / emoji / cost(积分) / tag / desc。下架某商品即从数组删除该行。

🏪 萌星好物（MALL_PRODUCTS）

字段：id / name / emoji / price / vipPrice(可选) / tag / desc / url。price 如 "¥199"。
